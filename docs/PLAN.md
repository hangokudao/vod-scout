# VOD Scout 제품·개발 계획

상태: **0.3.2 구현·보안·설치 게이트 완료**
대상: Windows 10/11, 1인 버튜버·클리퍼

## 제품 정의

VOD Scout는 완성 쇼츠를 자동 제작하는 프로그램이 아니라, 긴 VOD에서 **먼저 확인할 15~90초 후보와 그 근거를 보여 주는 편집 보조 에이전트**다. 최종 채택은 사람이 결정한다. 공개 제품은 검토 가능한 오픈소스와 비개발자가 설치할 수 있는 Windows 설치 EXE를 함께 제공한다.

## 현재 구현 범위

### 실제 기능

- 로컬 영상 파일 입력
- 공개 YouTube 단일 영상 입력, 최대 720p 다운로드
- 내장 yt-dlp·Deno·FFmpeg로 다운로드, 취소와 `.part` 재개
- 내장 `ffprobe`로 길이·오디오 스트림 확인
- FFmpeg로 10분·16 kHz mono 청크 추출
- whisper.cpp `base`를 한국어로 고정해 타임스탬프 전사
- 무음·영어 반복·낮은 고유 단어 비율 환각 필터
- 1초 RMS 오디오 반응과 발화 밀도 계산
- 우측 38% 화면의 5초 간격 키프레임 채팅 움직임 계산
- 45초 후보 창, 시간 겹침과 전사 유사도 중복 제거
- 오디오·발화·채팅 움직임 규칙 순위
- 최대 8개 후보와 근거·전사·타임코드 표시
- 후보 클릭 시 해당 시점의 H.264/AAC 검토 프록시 자동 재생
- 경과 시간·예상 남은 시간
- 작업 용량·삭제, 타임코드 복사, CSV 내보내기
- 취소, 자식 프로세스 종료, 청크 재개, 앱 재실행 복원
- 채택·제외·보류
- NSIS Windows 설치본

### 명시적으로 미구현

- 채팅 글자 OCR과 사용자가 지정하는 ROI
- 웃음 전용 모델, 화자 분리
- LLM 재순위와 개인화 학습
- 완성 쇼츠·편집 프로젝트 내보내기
- GPU 전사 가속

## 비용 원칙

- 기본 분석 API 비용 0원
- 영상·오디오·전사를 외부로 전송하지 않음
- 모델과 도구는 설치본에 포함
- 전체 프레임 OCR 금지
- 전체 전사를 LLM에 보내지 않음
- 장시간 영상은 한 청크씩 처리·삭제해 디스크 폭증 방지
- 합방이 아닌 1인 방송에서 화자 분리 기본 비활성

## 다음 완료 게이트

장시간 성능보다 먼저 `docs/SECURITY-AUDIT-2026-08-02.md`의 HIGH 보안 항목을 해결한다. ACL·설치본 무결성·고아 작업 개인정보가 `HOLD`인 동안 새 설치본을 배포하거나 교체하지 않는다.

0.3.1은 1시간 5분 실제 한국어 자료를 끝까지 처리했다. “8시간 VOD 사용 가능”으로 부르려면 아래가 추가로 필요하다.

1. 30분·2시간·8시간 파일 각각 끝까지 완료
2. 처리 중 취소 후 남은 FFmpeg/Whisper 프로세스 0개
3. 앱 강제 종료 후 마지막 완료 청크부터 재개
4. 임시 WAV 최대 한 청크만 존재
5. 후보 타임코드가 전사 근거와 일치
6. 피크 메모리와 처리 시간 기록
7. 최소 3개 VOD에서 사람이 “먼저 볼 가치가 있다”고 판정한 후보 비율 기록

현재 자동 테스트는 한국어 로컬 2분과 1시간 5분의 기능 연결을 증명하지만, 사람 기준 하이라이트 품질이나 2시간·8시간 성능을 증명하지 않는다.

v0.3.2의 세 분석 모드와 RC 순서는 `docs/V0.3.2-PLAN.md`가 정본이다. Git 기준선과 private push는 `docs/GIT-PRIVATE-REPOSITORY-PLAN.md`, 공개 소스와 설치 EXE 배포는 `docs/OPEN-SOURCE-RELEASE-PLAN.md`를 따른다.

| 위험 | 현재 대응 |
|---|---|
| CPU 전사가 매우 느림 | base 모델, 최대 8 thread, 청크 재개 |

| 설치 파일 크기 | 오프라인·무구독과의 의도된 교환 관계 |
