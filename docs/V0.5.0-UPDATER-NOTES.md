# VOD Scout v0.5.0-rc.1 업데이트 안내

v0.5.0-rc.1은 unsigned GitHub Pre-release이며 자동 업데이트 대상으로 배포하지 않습니다.

`bundle.createUpdaterArtifacts`는 `false`이고 `.sig`, `latest.json`, updater zip은 생성·배포하지 않습니다. 사용자는 새 버전을 GitHub Release에서 직접 확인해야 합니다. 상세 결과와 알려진 한계는 [릴리스 작업 정본](V0.5.0-RELEASE.md)과 [rc.1 릴리스 노트](V0.5.0-RC1-RELEASE-NOTES.md)를 따릅니다.
