# VOD Scout v0.3.2 릴리스 기록

상태: **RC 보안·설치 게이트 PASS · public 배포 검증 중 · 8시간 실시간 회귀는 긴급 릴리스 승인에 따라 HOLD**
문서 성격: 구현·보안·테스트·패키지·공개 배포의 정본 기록.

## 목표와 비범위

### 목표

- SEC-001~010의 HIGH·MEDIUM 보안 문제 해결
- `빠른 분석`, `구간 지정`, `전체 정밀 분석` 제공
- 분석 범위·도구·모델·체크포인트 provenance 저장
- 실제 1~2시간 YouTube 영상과 8시간 빠른 분석 검증
- 공개 소스와 Windows 설치 EXE를 함께 제공하는 첫 오픈소스 릴리스

### 비범위

- GPU 전사의 공식 지원
- 채팅 영역 자동 탐색과 OCR
- LLM 재순위·개인화 학습
- 완성 쇼츠 렌더링
- Authenticode 인증서 구매

## 사용자 변경 사항

### Added

- 장시간 영상용 `빠른 분석`
- 원본 타임코드를 유지하는 `구간 지정`
- 기존 전체 전사에 해당하는 `전체 정밀 분석`
- 전체 작업 목록·용량·선택 삭제·전체 삭제
- 분석 모드와 실제 처리 범위를 보여 주는 결과 근거

### Changed

- ETA를 원본 전체 길이가 아니라 실제 분석 대상 길이 기준으로 계산
- yt-dlp 후보 버전을 staging에서 검증하고 실패 시 고정 control 버전으로 롤백
- 설치 파일을 Git 커밋이 아닌 public GitHub Release 자산으로 제공

## 내부 변경 사항과 체크포인트 호환성

- `pipeline-provenance.json`에 앱 빌드, 입력 fingerprint, 분석 모드·범위·전사 예산, 도구·모델 해시, backend, ROI, ranker를 기록한다.
- 분석 범위·Whisper 설정·ROI·ranker 변경에 따라 필요한 단계만 무효화한다.
- v0.3.1 체크포인트는 fingerprint가 일치하지 않으면 안전하게 재계산한다.
- 원본 경로는 provenance와 공개 validation 결과에 직접 기록하지 않는다.

현재 결과: **PASS · v0.3.1 미완료 작업만 안전하게 초기화하고 완료된 검토 작업은 보존**

## PR 형식 자체 리뷰

private `hangokudao/vod-scout-dev`의 실제 PR과 로컬 자체 리뷰를 함께 기록한다.

### 변경 파일

- 분석 모드·체크포인트·runtime 무결성·저장 경계·updater·UI·문서·CI를 포함한다.
- 설치 EXE와 updater 패키지는 Git에 넣지 않고 Release 자산으로 분리한다.

### 위험과 회귀 가능성

- 분석 범위가 원본 타임코드와 어긋날 위험
- fingerprint 오류로 다른 옵션의 체크포인트가 혼합될 위험
- 빠른 분석이 조용하지만 중요한 장면을 누락할 위험
- 장시간 프레임·전사 데이터가 메모리나 디스크에 누적될 위험
- 보안 수정이 플레이어·CSV·삭제 기존 흐름을 깨뜨릴 위험
- installer와 공개 태그의 산출물이 달라질 공급망 위험

## 알려진 문제

- GPU 전사, 채팅 OCR·자동 ROI, LLM 재순위·개인화는 이번 버전 범위 밖이다.
- 코드 서명이 없으면 Windows SmartScreen 경고가 표시될 수 있다.
- 8시간 전체 정밀 분석은 별도 PASS 결과 전까지 지원을 주장하지 않는다.
- 라이선스는 Apache-2.0으로 결정·반영했다.

## 롤백 방법

- 구현 중 실패하면 마지막 PASS인 v0.3.1 소스 기준선으로 돌아가되, 기존 v0.3.1 설치본은 보안 HOLD 상태이므로 공개 재배포하지 않는다.
- yt-dlp 후보 버전 실패 시 검증된 control 버전과 분리된 캐시로 복원한다.
- 공개 후 치명적 문제가 발견되면 같은 파일명을 덮어쓰지 않는다. 릴리스를 철회하고 수정 patch 버전을 새 태그·새 해시로 배포한다.
- 사용자 작업 데이터 삭제나 기존 설치 폴더 변경은 별도 승인 없이 롤백 수단으로 사용하지 않는다.
