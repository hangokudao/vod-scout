## 기능 추가

- 없음. v0.3.4는 안정성·접근성 후속 패치입니다.

## 변경

- 화면 오른쪽 위 설정 진입점에 톱니바퀴 아이콘과 `설정` 문구를 표시합니다.
- 어두운 화면의 입력 카드 배경을 테마 변수로 맞춰 제목·설명을 읽기 쉽게 합니다.
- 취소 요청 시 현재 작업의 자식 프로세스만 제한 시간 안에 종료하도록 감독합니다.

## 버그 수정

- 취소가 오래 `취소 중…`에 머물 수 있던 경로를 작업 범위 종료로 줄였습니다.
- 내려받기 병합 중 열린 파일 용량을 표본 수집하는 측정 도구를 보완했습니다.

## 보안

- 새 외부 AI·API 전송이나 API 키 저장 경로를 추가하지 않았습니다.
- 프로세스 종료 범위는 현재 작업의 확인된 자식 프로세스 트리로 제한합니다.

## 알려진 문제

- Windows Authenticode 인증서가 없어 첫 설치에서 SmartScreen 경고가 표시될 수 있습니다.
- 업데이트 뒤 Windows 제거 프로그램 목록의 표시 버전이 오래된 값일 수 있습니다. 앱·실행 파일 버전과 별개로 확인합니다.
- 이 노트는 앱 내 updater 안내 문구용입니다. 패키징·설치 EXE·updater 서명·공개 자산 재다운로드 검증은 별도 릴리스 게이트이며 현재 `HOLD`입니다.
