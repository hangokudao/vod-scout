# VOD Scout v0.3.3 UI·검토 개선 계획

상태: **v0.3.3 공개 배포·실제 업데이트 전환 PASS · Authenticode와 제거 프로그램 레지스트리 버전 표시는 HOLD**
최종 통합·배포: Codex/Sol 단독. 최종 변경은 PR #6을 squash merge하고 exact merge commit `5f756af7390325a99f2820a424f7d4ef05334d14`에서 검증·배포했다.

## 목표

v0.3.3은 분석 엔진을 크게 바꾸지 않고 후보를 더 빨리 비교하고 검토할 수 있게 만드는 버전이다. 새 기능을 늘리는 것보다 이미 계산된 결과를 찾고, 정렬하고, 전후 맥락과 함께 재생하는 흐름을 먼저 정리한다.

## 현재 기능과 중복 방지

- 업데이트 확인, 안정 버전 다운로드, 서명 확인, 앱 재시작 흐름은 v0.3.2에 이미 있다. 새로 만들지 않고 접근성과 상태 표시만 개선한다.
- 후보를 선택하면 앱 안의 영상 플레이어가 해당 시점부터 재생한다. v0.3.3에서는 이 경로를 유지하면서 전후 맥락 탐색을 보강한다.
- 후보는 현재 점수순으로 제공된다. 원본 점수는 바꾸지 않고 사용자가 보는 순서만 선택할 수 있게 한다.

## 사용자 요구사항

### 1. 후보 정렬과 좁혀 보기

사용자는 다음 기준으로 후보 목록을 정렬할 수 있어야 한다.

- 종합 점수 높은 순
- 원본 영상 시간순
- 오디오 반응 높은 순
- 발화 밀도 높은 순
- 채팅 움직임 높은 순
- 채택·보류·제외 상태

정렬을 바꿔도 선택 중인 후보, 채택 상태, 원본 타임코드는 변하지 않아야 한다. 점수가 같은 후보는 원본 시간순으로 고정해 목록이 흔들리지 않게 한다.

### 2. 시스템 화면 설정

- 기본값은 Windows의 밝은 화면·어두운 화면 설정을 따른다.
- 사용자가 `시스템 설정 사용`, `밝게`, `어둡게` 중 하나를 선택할 수 있다.
- 선택은 앱을 다시 실행해도 유지한다.
- 색상만 반전하지 않고 텍스트 대비, 포커스 표시, 경고·성공 상태를 두 화면에서 모두 확인한다.

### 3. 후보 전후 맥락

- 선택한 후보 앞뒤의 영상과 음성 인식 문장을 함께 확인할 수 있어야 한다.
- 플레이어에는 `후보 시작`, `맥락 시작`, `맥락 끝`으로 이동하는 동작을 제공한다.
- 후보 경계가 문장 중간이나 반응 직전에 끊기는지 판단할 수 있도록 앞뒤 문장과 타임코드를 보여 준다.
- 맥락 범위는 원본 영상 범위를 벗어나지 않아야 하며, 실제 기본 길이는 사용자 검토 테스트 후 고정한다.
- 맥락 영상은 기존 검토 프록시를 재사용하고 같은 구간을 반복 생성하지 않는다.

### 4. 업데이트 확인 접근성

- 앱 실행 시 자동 확인과 설정 화면의 `업데이트 확인` 버튼을 유지한다.
- 현재 버전, 확인 시각, 최신 상태, 새 버전, 네트워크 오류를 구분해 표시한다.
- 분석 중에는 설치하지 않고 분석 종료 또는 취소 후 진행한다.
- GitHub에 접속하지 못해도 로컬 영상 분석과 기존 작업 검토는 정상 동작한다.
- v0.3.3 정식 배포에서는 서명된 v0.3.2 설치본이 v0.3.3을 발견하고 내려받아 설치한 뒤 다시 실행되는 실제 전환을 확인한다.

### 5. UI 정리

- 입력, 분석 진행, 후보 검토, 설정을 한 화면에 무리하게 동시에 노출하지 않는다.
- 후보 목록에는 비교에 필요한 점수·시간·상태만 먼저 보이고 상세 근거는 선택 후 표시한다.
- 키보드 `J`/`K`, `A`, `X`와 동일한 화면 버튼을 유지한다.
- 1280px 이상, 900~1279px, 899px 이하 화면에서 핵심 행동이 가려지지 않아야 한다.

## 추가로 필요한 지원 기능

- 정렬·화면 설정을 저장하는 사용자 설정 구조
- 후보 선택을 유지하는 안정적인 후보 식별자
- 후보와 맥락 프록시의 생성 옵션을 구분하는 캐시 키
- 업데이트 마지막 확인 결과와 오류를 보여 주는 상태 모델
- 접근성 확인을 위한 키보드 포커스·색상 대비 점검표

## 이번 버전에서 하지 않는 것

- GPU 음성 인식
- Whisper 모델 교체와 정확도 단계
- 채팅 글자 인식과 채팅 영역 자동 탐색
- 전체 영상의 이야기 구간 탐색
- 사용자 API 또는 외부 LLM 연동
- 설치 파일에 새 대형 모델 포함

- 측정 한계: YouTube 영상·음성 병합 중 열린 출력 파일 길이를 표본 수집기가 읽지 못해 내려받기 단계의 정확한 순간 최대 임시 용량은 `HOLD`다. 닫힌 입력 파일로 확인한 최소치는 `7,070,731,050 bytes`다.

## 완료 조건

1. 모든 정렬 기준이 같은 입력에서 항상 같은 순서를 만든다.
2. 정렬·화면 설정을 바꾸고 앱을 다시 실행해도 선택이 유지된다.
3. 밝은 화면·어두운 화면에서 텍스트, 포커스, 경고 상태를 구분할 수 있다.
4. 후보·맥락 시작·맥락 끝 이동이 원본 타임코드와 일치한다.
5. 앞뒤 음성 인식 문장이 후보 타임코드와 같은 원본을 가리킨다. **PASS: 실제 입력의 75초 맥락 영상과 타임코드 문장을 검토했다.**
6. 업데이트 서버 연결 실패가 기존 오프라인 기능을 막지 않는다.
7. updater 기능이 있는 공개 v0.3.2 설치본에서 v0.3.3으로 실제 업데이트·설치·재실행이 완료된다. **PASS: 공개 updater 서명을 검증한 뒤 설치·재실행했고 앱과 실행 파일이 `v0.3.3`, 업데이트 화면이 `최신 상태`임을 확인했다.**
8. 기존 v0.3.2 작업과 체크포인트를 그대로 열 수 있다. **PASS: 업데이트 뒤 기존 작업 14개와 현재 작업 `#92bbf85a`, 후보 8개를 열었고 핵심 상태·체크포인트 5개 SHA-256이 업데이트 전과 일치했다.**
9. 제품 코드 구현 전후의 관련 단위 테스트와 실제 영상 검토 흐름이 PASS한다. **PASS: 기본 테스트 4개와 승인된 8시간 53분 입력의 생성·재개·검토 흐름을 확인했다.**

7번 완료 근거: 공개 v0.3.2 설치본에서 앱의 `지금 업데이트`를 실행한 뒤 `D:\VOD Scout\vod-scout.exe`가 `0.3.3`으로 교체되고 앱이 다시 실행됐다. 설정 화면은 현재 버전 `v0.3.3`과 `최신 상태`를 표시했다. Windows 제거 프로그램 레지스트리의 `DisplayVersion`은 `0.3.2`로 남아 있어 별도 `HOLD`다.

구현하지 않았거나 직접 확인하지 않은 항목은 `PASS`로 기록하지 않는다.
