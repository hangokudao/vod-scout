계획 정본: [V0.4.0 장시간 최적화·이야기 구간 탐색 계획](V0.4.0-PLAN.md)

## 목표와 비범위

v0.4.0은 2~8시간 입력에서 계산량과 저장 공간을 통제하면서 전체 영상 흐름과 수분 단위 이야기 후보를 찾는 버전이다. YouTube 입력은 품질을 통과한 원문 자막을 먼저 사용하고, 부족하거나 의심스러운 구간만 로컬 Whisper로 확인한다. Whisper가 필요하면 실제 시험을 통과한 GPU를 우선 사용하고 실패한 청크만 CPU로 처리한다.

완성 쇼츠 자동 제작, 전체 영상 무조건 정밀 음성 인식, 전체 프레임 OCR, Ollama·대형 로컬 언어 모델, 개발자 공용 API 키, Authenticode 인증서 구매·생성은 범위에 포함하지 않는다.

**이번 문서 갱신 범위:** P0 병합·검증 결과와 PASS/HOLD 경계만 기록한다. **v0.4.0 설치·배포 실행 계획은 포함하지 않는다** (P0 전 게이트 PASS 조건 미충족).

## 사용자 변경 사항

공개 설치본 버전은 여전히 **0.3.4**다. v0.4.0 사용자 배포 변경은 없다. main에 들어간 P0 코드(개발 경로)의 동작 요약:

- 체크포인트가 호환되지 않으면 미디어 중간 결과만 다시 계산하고, 작업 id·소스·분석 설정은 유지한다.
- 범위 지정 분석 후보는 지정 구간 안으로만 나오고, 음량·발화 근거가 없는 창은 빠진다.
- 분석 시작 전 작업 폴더 볼륨 여유 공간이 부족하면 한국어로 막고 시작한다(live 저용량 E2E는 HOLD).
- 취소 뒤 완료한 청크부터 재개할 수 있다(실제 미디어 H10 PASS).

계획된 나머지 사용자 변경(성능 단계, 자막 출처, 이야기 후보, GPU 우선, 선택형 API)은 P1~P6이며 아직 구현·배포하지 않았다.

## 내부 변경 사항과 체크포인트 호환성

P0(현재 경로 정확성·복구)이 `main` `cca7a9e49301b46c857a76e4203eecf008923eed`에 병합됐다. 공개 버전 정본은 `0.3.4`를 유지한다.

- 입력 지문·길이·도구·모델 해시·언어·분석 범위·후보 계산 버전(`rules-v0.4.0-p0`)으로 미디어 체크포인트 호환성을 판정한다. schema 3 이하거나 불일치면 미디어 중간 결과만 다시 계산한다. 작업 id·소스·분석 설정과 목록 스냅샷은 유지한다.
- 호환되지 않는 미디어 체크포인트를 버리고 새로 만들 때, 작업 스냅샷의 `completed_units`가 이미 진행돼 있어도 하드 실패하지 않고 미디어 청크 처리부터 안전하게 다시 시작한다 (H5F F1).
- 체크포인트·음성 인식 결과·채팅 움직임·provenance·작업 스냅샷은 마지막 정상 세대를 `.prev`로 보존한 뒤 교체한다.
- 범위 지정 후보를 분석 구간 안으로 제한하고, 음량·발화 근거가 없는 창은 제외한다.
- 분석 시작 전 작업 폴더 볼륨의 여유 공간을 검사하고 부족하면 시작을 막는다. **YouTube acquisition 경로에는 다운로드 직전 free-space 검사가 없다** (H9).
- 미리보기 FFmpeg도 작업 취소 플래그를 따르며, 취소 완료 활동은 도구 종료 사실을 남긴다. 측정하지 않은 종료 소요 시간(ms)은 활동에 넣지 않는다.
- 자막 색인·이야기 후보·GPU 우선 Whisper·선택형 API(P1~P6)는 아직 구현하지 않았다.
- 전체 PCM·원본 프레임·전체 장시간 텍스트를 한꺼번에 메모리에 올리지 않는다.
- 기존 v0.3.2·v0.3.3·v0.3.4 작업 목록·스냅샷은 보존하고 호환되지 않는 미디어 체크포인트만 다시 계산한다.

## 버그 수정

- 호환되지 않는(schema 3·지문/도구/ranker 불일치) 미디어 체크포인트를 폐기한 뒤, 작업 스냅샷 `completed_units`가 probe 이후까지 진행된 상태에서 재개하면 “작업 스냅샷보다 미디어 체크포인트가 뒤에 있어…”로 하드 실패하던 문제 — 미디어 중간 결과만 다시 계산하고 작업 정체성·소스는 유지하도록 수정 (PR #11 후속 `d13b864`, H5F F1). 회귀: cargo lib 41 pass / 1 ignored.

## 보안 수정

- 자막 확보가 실패해도 로그인·쿠키·나이 제한·봇 확인을 우회하지 않는다.
- 원본 영상·음성·전체 장시간 자막을 외부 API로 보내지 않는다.
- 사용자 API 키는 Windows 보안 저장소에만 보관하고 설정 파일·작업 폴더·체크포인트·로그·내보내기에 남기지 않는다.
- GPU 실행 파일·DLL·모델은 고정된 출처·파일 목록·SHA-256으로 검증한다.
- API·GPU가 없어도 로컬 CPU 규칙 기반 경로로 완료한다.
- H8/H11 실측에서 제품 경로의 외부 AI 전송은 관측되지 않았다(YouTube acquisition HTTPS만).

- 성능 측정 전에는 “8시간 완전 지원”, “GPU 지원”, “이야기 구간 정확 탐지”라고 표시할 수 없다. H11 overall PASS는 **무중단 single-shot HOLD**와 함께 기록한다.

## 롤백 방법

P0 코드가 들어간 개발/소스 경로에서 문제가 있으면 검증된 공개 설치본 **v0.3.4**로 되돌린다. 기존 작업 폴더와 `current-job.json`은 삭제하지 않는다. 새 스키마는 읽기 전 백업 또는 마지막 정상 세대를 보존하고, 이전 버전이 읽을 수 없는 중간 결과만 명시적으로 다시 계산한다. v0.4.0 공개 빌드 시점의 직전 버전·설치 파일 SHA-256은 그때 고정한다.
