## 기능 추가

- 후보를 종합 점수, 원본 시간, 오디오 반응, 대화 밀도, 채팅 움직임, 판정 상태로 정렬할 수 있습니다.
- Windows 시스템 설정을 따르는 밝은 화면·어두운 화면과 수동 선택을 제공합니다.
- 후보 앞뒤 영상과 원본 타임코드, 음성 인식 문장을 함께 확인할 수 있습니다.

## 변경

- 정렬 순서를 바꿔도 후보 ID를 기준으로 선택과 판정을 유지합니다.
- 업데이트 확인 중, 최신 상태, 새 버전, 분석 종료 후 설치 대기, 연결 실패를 구분합니다.

## 버그 수정

- 같은 시작 초를 가진 후보가 선택 상태를 공유할 수 있던 문제를 수정했습니다.
- 후보·맥락 미리보기 임시 파일이 FFmpeg에서 MP4로 인식되지 않던 문제를 수정했습니다.

## 보안

- 새 외부 AI·API 전송이나 API 키 저장 경로를 추가하지 않았습니다.
- 미리보기 파일 접근 범위는 앱 작업 폴더와 격리된 E2E 경로로 제한합니다.

## 알려진 문제

- Windows Authenticode 인증서가 없어 첫 설치에서 SmartScreen 경고가 표시될 수 있습니다.
- 빠른 분석은 전체 영상의 일부를 시간대별로 골라 처리하므로 전체 정밀 분석과 결과가 다릅니다.
