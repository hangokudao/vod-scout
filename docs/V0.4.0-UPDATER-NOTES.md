## 기능 추가

- 긴 영상을 여러 구간으로 처리하고 완료한 지점부터 이어서 분석합니다.
- YouTube 미디어를 받기 전에 선택된 영상·음성 크기와 후속 분석에 필요한 저장 공간을 확인합니다.

## 변경

- 입력 파일, 도구, 모델, 언어와 분석 범위가 현재 작업과 맞는 중간 결과만 재사용합니다.
- 분석 범위 밖이거나 실제 음량·대화 근거가 없는 후보는 결과에서 제외합니다.
- 마지막 정상 체크포인트를 한 세대 보존해 최신 파일이 손상됐을 때 복구합니다.

## 버그 수정

- 호환되지 않는 중간 결과를 버린 뒤 작업 재개가 멈출 수 있던 문제를 고쳤습니다.
- YouTube 내려받기와 병합 도중 저장 공간이 부족해질 수 있던 경로를 전송 전에 차단합니다.
- 취소 시 현재 작업에서 시작한 하위 프로그램이 남을 수 있는 경로를 정리했습니다.

## 보안

- 영상 정보 확인 출력의 크기를 제한하고 원문 전체와 진단 출력 전체를 제품 로그에 저장하지 않습니다.
- 새 외부 AI·유료 API 전송과 API 키 저장 경로를 추가하지 않았습니다.

## 알려진 문제

- Windows Authenticode 인증서가 없어 첫 설치에서 SmartScreen 경고가 표시될 수 있습니다.
- YouTube가 일시적으로 403 또는 봇 확인을 반환할 수 있습니다. 로그인이나 CAPTCHA 우회는 지원하지 않습니다.
- GPU 음성 인식, 채팅 글자 인식과 외부 AI 평가는 이번 버전에 포함하지 않습니다.
