## 후순위

채택·제외 기록이 충분히 쌓인 뒤에만 다음 항목을 검토한다.

1. 사용자가 직접 등록하는 DeepSeek·OpenAI 호환 API 선택 연결
2. LLM을 이용한 상위 후보 재정렬
3. 사용자별 후보 순위 조정

로컬 AI 실행기와 대형 모델은 포함하지 않는다. 사용자 API 선택 연결은 제품 방향으로 승인됐지만 이번 문서 변경에는 구현을 포함하지 않으며, 별도 버전 구현 범위에서 보안 저장·전송 동의·비용 한도 검사를 먼저 통과해야 한다.
