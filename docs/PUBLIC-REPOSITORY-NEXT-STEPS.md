## 현재 문서 반영 범위

1. v0.4.0 공개 완료와 v0.5.0 구현 전 상태를 정본 문서에 맞춘다.
2. 시청자 약 5~30명, 익명 채팅 오버레이 환경을 기록한다.
3. 작성자·메시지 수를 추정하지 않고 현재 VOD의 고정 채팅 영역 움직임이 내부 평소 분포보다 증가한 경우만 보조 신호로 사용하는 원칙을 고정한다.
4. 음성 인식 품질, 자원 제한, 후보 수·품질, 순차 대기열, GPU→CPU 대체 처리와 제한적 병렬 처리의 완료 조건을 연결한다.
5. 자동 재분석·자동 재시작·GPU 재시도·병렬 전환이 반복되지 않는 종료 조건을 고정한다.

완료 조건:

- 계획·릴리스·아키텍처·UI·테스트·인계 문서가 같은 포함·비범위를 가리킨다.
- 비밀값, 개인 영상, 작업 로그, 설치 파일이 Git 변경에 포함되지 않는다.
- Markdown 형식, 상대 링크와 `git diff --check`가 통과한다.
- Oracle은 읽기 전용 검수만 수행하고 저장소 파일을 수정하지 않는다.

## v0.5.0 구현 순서

1. 사용 권한과 보관 범위를 확인한 기준 영상에서 이상한 반복·깨진 문자와 현재 자원 사용을 재현한다.
2. 음성 인식 품질 상태와 후보 제목 보호를 구현한다.
3. 단계별 자원 측정과 앱 반응성 제한을 구현한다.
4. 후보 8·20·30개 설정과 내용 품질 경고를 구현한다.
5. 기본 동시 분석 1개의 순차 대기열과 재실행 복원을 구현한다.
6. 실제 시험을 통과한 GPU와 실패 청크의 CPU 1회 대체 처리를 구현한다.
7. 순차 대기열이 안정된 뒤에만 제한적 병렬 처리를 측정하고, 안전하지 않으면 제공하지 않는다.

기능별 최소 테스트와 실제 사용자 흐름을 통과한 뒤 다음 단계로 넘어간다. 구현·PR·병합·배포 승인은 서로 별개다.

## v0.5.0에 포함하지 않는 후속 작업

- YouTube 자막 검색과 검색 결과의 원본 시각 이동
- 수분 단위 이야기 후보와 멀리 떨어진 관련 장면 연결
- 채팅 글자 인식·작성자 식별·채팅 영역 자동 탐색
- 사용자 API·외부 AI 후보 재정렬
- 완성 쇼츠 렌더링·자동 게시
- Authenticode 인증서 구매·적용

이 항목들은 별도 버전과 별도 승인 없이 구현하지 않는다.
