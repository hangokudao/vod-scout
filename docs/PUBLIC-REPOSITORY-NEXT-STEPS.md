## 이번 공개 반영 내용

이번 공개 반영은 문서와 검증 기록을 정확히 맞추는 작업으로 제한한다.

1. v0.3.2 최종 검증 기록을 실제 공개 결과와 맞춘다.
2. `HANDOFF.md`를 v0.3.2 공개 완료 기준으로 갱신한다.
3. 자동 생성 스키마의 줄바꿈 차이는 변경에서 제외한다.
4. 공개 저장소와 비공개 개발 저장소의 이력을 섞지 않고 공개 저장소 기준 브랜치에 문서 변경만 적용한다.
5. 문서 변경을 검토하고 기본 검사를 통과한 내용만 공개 저장소에 반영한다.

- 비밀값, 개인 영상, 작업 로그, 설치 파일이 Git 변경에 포함되지 않는다.
- 실제 공개 배포 결과와 문서의 파일명·크기·해시·검증 결과가 일치한다.

- 문서 변경 검토와 형식 검사가 통과한다.

## 성능과 기능 개선 후보

아래 항목은 이번 공개 반영에 구현하지 않는다.

1. v0.3.2 CPU 경로의 성능 기준선 측정
2. 서로 다른 방송 화면의 1~2시간 실제 영상 회귀 검사
3. GPU 자동 감지·시험 전사와 CPU 대체 처리
4. 8시간 영상의 빠른 분석 안정성·처리 시간·메모리·저장 공간 측정
5. 사용자가 채팅 영역을 직접 지정하는 기능
6. 채팅 움직임이 활발한 구간만 선별해 글자를 읽는 기능
7. 방송 화면이 바뀔 때 채팅 영역을 다시 찾는 기능
8. yt-dlp 버전 확인·업데이트·이전 검증 버전 복구 절차의 정기 점검

## 후순위

채택·제외 기록이 충분히 쌓인 뒤에만 다음 항목을 검토한다.

1. 선택형 Ollama 또는 다른 로컬 모델 연결
2. 사용자별 후보 순위 조정
3. LLM을 이용한 최종 후보 재정렬

유료 API 연동은 사용자가 별도로 승인하기 전까지 제품 실행 경로에 추가하지 않는다.
