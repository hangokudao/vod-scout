# 오픈소스 라이선스 결정 기록

상태: **결정 완료 · Apache-2.0**

## 결정할 내용

사용자가 2026-08-02 공개 저장소와 배포물에 **Apache License 2.0**을 적용하도록 승인했다. 루트 `LICENSE`, Rust·npm 패키지 metadata와 공개 문서의 식별자는 `Apache-2.0`으로 통일한다.

## 후보

| 후보 | 장점 | 고려 사항 |
|---|---|---|
| Apache License 2.0 | 상업·개인 사용 허용, 명시적 특허 허여와 NOTICE 규칙 | MIT보다 문서가 길고 NOTICE 의무를 이해해야 함 |
| MIT License | 짧고 익숙하며 사용·수정·재배포가 단순 | 명시적 특허 허여 문구가 Apache-2.0보다 약함 |

결정: **Apache-2.0**. 설치형 앱과 향후 외부 기여에서 특허 허여 조건이 비교적 명확한 점을 반영했다. 이는 법률 자문이 아니다.

## 반영 결과

1. 정식 Apache License 2.0 원문을 루트 `LICENSE`에 추가했다.
2. Rust·npm metadata에 `Apache-2.0`을 반영했다.
3. 제3자 번들 라이선스는 `THIRD-PARTY-NOTICES.md`와 설치 리소스에 별도로 유지한다.
4. 공개 소스와 설치 패키지에서 동일 고지를 검증한다.
