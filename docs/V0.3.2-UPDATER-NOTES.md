## 기능 추가

- 빠른 분석, 구간 지정, 전체 정밀 분석
- 저장된 작업별 용량 확인과 선택·전체 삭제
- GitHub Releases 기반 서명 검증 자동 업데이트

## 변경

- 빠른 분석은 전체 길이의 20%, 최소 30분·최대 120분을 시간대별로 분산 전사합니다.
- 채팅 움직임 frame을 스트리밍 처리해 장시간 메모리 누적을 제한합니다.
- yt-dlp는 검증된 최신 안정 버전을 앱 빌드에 고정합니다.

## 버그 수정

- 한국어 무음 전사 환각과 겹치는 후보를 줄였습니다.
- CSV 수식 실행 입력과 저장 경로 경계를 수정했습니다.
- 분석 설정이 달라졌을 때 이전 체크포인트가 섞이지 않게 했습니다.
- 손상된 snapshot을 가진 고아 작업도 전체 삭제할 수 있습니다.

## 보안 수정

- 자식 도구의 부모 비밀 환경 상속과 FFmpeg 네트워크 입력을 차단했습니다.
- 모든 번들 EXE·DLL·모델의 파일 목록과 SHA-256을 실행 전에 검증합니다.
- updater 서명 검증과 다운그레이드 차단을 적용했습니다.

## 알려진 문제

- Windows Authenticode 서명이 없어 첫 설치에서 SmartScreen 경고가 표시될 수 있습니다.
- GPU 전사, 채팅 OCR·자동 영역 탐색, LLM 재순위는 아직 지원하지 않습니다.
- 8시간 실제 영상 회귀와 전체 정밀 분석은 아직 검증되지 않았습니다.
