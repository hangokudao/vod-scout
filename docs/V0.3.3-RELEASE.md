# VOD Scout v0.3.3 릴리스 기록

상태: **PASS** (공개 배포·실제 업데이트·기존 작업 보존 완료. Authenticode와 제거 프로그램 레지스트리 버전 표시는 `HOLD`)

## 목표와 비범위

v0.3.3은 후보 비교와 원본 앞뒤 맥락 검토 흐름을 개선한다. GPU 음성 인식, 성능 단계, 8시간 최적화, 이야기 구간 탐색, 외부 API·LLM, 검색어 기능은 포함하지 않는다.

## 사용자 변경 사항

- 후보를 종합 점수, 원본 시간, 오디오 반응, 대화 밀도, 채팅 움직임, 판정 상태로 정렬한다.
- 정렬 순서를 바꿔도 후보 ID를 기준으로 선택과 판정을 유지한다. 동점은 원본 시간과 후보 ID 순으로 고정한다.
- Windows 시스템 설정을 따르는 밝은 화면·어두운 화면과 수동 선택을 제공하고 설정을 저장한다.
- 후보 앞뒤 영상 구간, 원본 타임코드, 음성 인식 문장을 표시하고 후보 시작·맥락 시작·맥락 끝으로 이동한다.
- 업데이트 확인 중, 최신 상태, 새 버전, 분석 종료 후 설치 대기, 연결 실패를 구분한다.

## 내부 변경 사항과 체크포인트 호환성

- Candidate ID는 시작·끝 원본 초를 함께 사용해 안정적이며 같은 시작·다른 끝 구간을 구분한다.
- 맥락 구간은 원본 시작·끝으로 제한되고 기본 앞뒤 여유 시간은 15초다. 저장된 후보에는 맥락 범위와 타임코드 문장이 포함된다.
- 맥락 프록시 캐시 키는 작업 ID, 후보 ID, 원본 fingerprint, 맥락 시작·끝, 프록시 종류를 모두 포함한다.
- 이전 후보 snapshot은 새 맥락 필드가 없어도 기본값으로 읽도록 유지한다.

## 버그 수정

- 같은 시작 초를 가진 후보가 선택 상태를 공유할 수 있던 위험을 시작·끝 구간 ID로 수정했다. 동일 입력 재생성과 같은 시작·다른 끝 회귀 테스트를 추가했다.
- 실제 미디어에서 후보·맥락 미리보기를 만들 때 임시 이름이 `.mp4.tmp`가 되어 FFmpeg가 출력 형식을 고르지 못하던 문제를 수정했다. 최종 파일의 MP4 확장자를 유지하는 `.tmp.mp4`를 사용하고 회귀 테스트를 추가했다.

## 보안 수정

새 외부 전송이나 API 키 경로는 추가하지 않았다. 프록시는 기존 작업 폴더 경계와 원본 fingerprint 검증을 유지한다. 측정용 검토 재생은 설정에 이미 허용된 `$APPLOCALDATA/e2e-*` 격리 경로에서 수행했으며 Asset Protocol 범위를 넓히지 않았다.

## 알려진 문제

- Windows 코드 서명 인증서가 없으면 SmartScreen 경고가 표시될 수 있다.
- 현재 PC의 CurrentUser·LocalMachine 인증서 저장소에서 Authenticode 코드 서명 인증서를 찾지 못했고 `signtool.exe`도 확인되지 않았다. 구매하거나 대체 인증서를 만들지 않으며 `HOLD`다.
- updater 뒤 실행 파일과 앱은 `v0.3.3`이지만 HKCU 제거 프로그램 레지스트리의 `DisplayVersion`은 `0.3.2`로 남아 있다. 원인과 Windows 앱 목록 표시 영향은 `HOLD`다.
- 8시간대 빠른 분석은 체크포인트 재개 포함 결과이며 내려받기 병합 순간의 정확한 최대 임시 용량은 `HOLD`다.
