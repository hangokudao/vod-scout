# VOD Scout v0.3.3 릴리스 기록

상태: **HOLD** (PR 준비 단계이며 설치본·실제 미디어·업데이트 전환 검증 전)

## 목표와 비범위

v0.3.3은 후보 비교와 원본 앞뒤 맥락 검토 흐름을 개선한다. GPU 음성 인식, 성능 단계, 8시간 최적화, 이야기 구간 탐색, 외부 API·LLM, 검색어 기능은 포함하지 않는다.

## 사용자 변경 사항

- 후보를 종합 점수, 원본 시간, 오디오 반응, 발화 밀도, 채팅 움직임, 판정 상태로 정렬한다.
- 정렬 순서를 바꿔도 후보 ID를 기준으로 선택과 판정을 유지한다. 동점은 원본 시간과 후보 ID 순으로 고정한다.
- Windows 시스템 설정을 따르는 밝은 화면·어두운 화면과 수동 선택을 제공하고 설정을 저장한다.
- 후보 앞뒤 영상 구간, 원본 타임코드, 음성 인식 문장을 표시하고 후보 시작·맥락 시작·맥락 끝으로 이동한다.
- 업데이트 확인 중, 최신 상태, 새 버전, 분석 종료 후 설치 대기, 연결 실패를 구분한다.

## 내부 변경 사항과 체크포인트 호환성

- Candidate ID는 시작·끝 원본 초를 함께 사용해 안정적이며 같은 시작·다른 끝 구간을 구분한다.
- 맥락 구간은 원본 시작·끝으로 제한되고 기본 앞뒤 여유 시간은 15초다. 저장된 후보에는 맥락 범위와 타임코드 문장이 포함된다.
- 맥락 프록시 캐시 키는 작업 ID, 후보 ID, 원본 fingerprint, 맥락 시작·끝, 프록시 종류를 모두 포함한다.
- 이전 후보 snapshot은 새 맥락 필드가 없어도 기본값으로 읽도록 유지한다.

## 버그 수정

- 같은 시작 초를 가진 후보가 선택 상태를 공유할 수 있던 위험을 시작·끝 구간 ID로 수정했다. 동일 입력 재생성과 같은 시작·다른 끝 회귀 테스트를 추가했다.

## 보안 수정

새 외부 전송이나 API 키 경로는 추가하지 않았다. 프록시는 기존 작업 폴더 경계와 원본 fingerprint 검증을 유지한다.

### 위험과 회귀 가능성

- 맥락 프록시 생성은 실제 미디어 파일과 Windows 도구 번들이 필요한 경로다.
- 업데이트·설치 전환과 실제 영상의 타임코드 일치는 아직 실행하지 않았다.
- 화면 테스트는 순수 정렬·설정·맥락·업데이트 상태 32개를 검증했으며, 실제 Tauri 영상 재생은 HOLD다.

### 발견 사항과 조치

- PASS: 입력 후보의 점수·판정을 바꾸지 않는 정렬과 결정적 동점 처리를 확인했다.
- PASS: 이전 snapshot의 누락 맥락 필드 기본값과 후보 ID 회귀 테스트를 확인했다.
- HOLD: 설치 EXE, SHA-256, 서명, 실제 미디어, 업데이트 전환을 PR 단계에서 확인하지 못했다.

## 설치본과 SHA-256

v0.3.3 설치본은 아직 만들지 않았다. 설치 파일명은 `VOD.Scout_0.3.3_x64-setup.exe`로 고정하며, 실제 크기·SHA-256·서명·SBOM은 설치 게이트 통과 뒤 `BUILD-MANIFEST.md`와 `SHA256SUMS.txt`에 기록해야 한다.

## 알려진 문제

- Windows 코드 서명 인증서가 없으면 SmartScreen 경고가 표시될 수 있다.
- 실제 미디어와 서명된 설치본 전환은 검증 전까지 HOLD다.
- 8시간 실제 입력의 처리 시간·메모리·저장 공간은 측정하지 않았다.

## 롤백 방법
