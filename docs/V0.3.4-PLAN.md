# VOD Scout v0.3.4 안정성·접근성 후속 패치 계획

상태: **완료(구현·공개 배포·인앱 updater·DisplayVersion·데이터 보존 PASS) · Authenticode/SmartScreen·Whisper 중 취소·과거 DisplayVersion 근본 원인 HOLD**

구현 결과 정본: [V0.3.4 릴리스 기록](V0.3.4-RELEASE.md)

## 목표

v0.3.4는 공개된 v0.3.3에서 실제 사용 중 확인된 문제만 수정하는 작은 패치다. 새 분석 기능을 추가하지 않고, 설정 진입점·다크 모드 대비·취소 완료·업데이트 뒤 Windows 버전 표시와 장시간 측정 근거를 바로잡는다.

## 범위

### 1. 설정 버튼 가시성

- 화면 오른쪽 위 버전 표시만 보고도 설정 진입점임을 알 수 있도록 톱니바퀴 아이콘, `설정` 문구, 버튼 경계와 마우스 올림·키보드 포커스 상태를 제공한다.
- 1280px 이상, 900~1279px, 899px 이하에서 버전과 설정 문구가 잘리거나 다른 상태 표시와 겹치지 않아야 한다.

### 2. 다크 모드 입력 카드 대비

- `.source-tabs button`의 고정된 밝은 반투명 배경을 테마 변수로 교체한다.
- 밝은 화면·어두운 화면에서 기본·마우스 올림·선택·비활성화·키보드 포커스 상태를 서로 구분한다.
- 입력 카드 제목과 설명처럼 일반 크기 글자는 WCAG AA 기준인 4.5:1 이상의 대비를 목표로 확인한다.

### 3. 취소 완료 지연

- 취소 요청부터 worker, yt-dlp, FFmpeg, Whisper와 하위 프로세스 종료, 체크포인트 저장, 최종 `CANCELLED` 반영까지 단계별 시간을 기록한다.
- 정상 종료 요청에 응답하지 않는 자식 프로세스에는 제한 시간을 적용하고, 제한 시간 뒤에는 해당 작업의 프로세스 트리만 종료한다.
- 취소 중에는 현재 종료 대상과 마지막 진행 시각을 표시한다. 완료되지 않았는데 `취소됨`으로 표시하지 않는다.
- 실제 YouTube 작업에서 60초 이상 `취소 중…`에 머무르면 패치 완료로 보지 않는다. 최종 제한 시간은 재현 측정과 자식 프로세스별 종료 시험 뒤 더 짧게 고정한다.

### 4. Windows 제거 프로그램 버전 표시

- v0.3.3에서 v0.3.4로 updater 설치한 뒤 앱·실행 파일·`uninstall.exe`와 HKCU 제거 프로그램 `DisplayVersion`이 모두 `0.3.4`인지 확인한다.
- NSIS 또는 Tauri updater의 레지스트리 갱신 경로를 격리 재현하고, 다른 앱의 제거 프로그램 항목을 변경하지 않는다.

### 5. 내려받기 임시 용량 측정

- YouTube 병합 중 열린 출력 파일도 실패 없이 표본 수집하도록 측정 도구를 보완한다.
- 입력 길이, 선택 스트림, 내려받기 파일, 병합 파일, 분석 WAV, 미리보기와 최종 작업 용량을 구분해 기록한다.
- 측정 도구 수정은 제품의 내려받기·분석 결과를 바꾸지 않아야 한다.

## 비범위

- YouTube 자막 우선 분석, 검색어 기능, 이야기 구간 탐색
- GPU 음성 인식과 Whisper 성능 단계
- OCR·채팅 영역 자동 탐색
- DeepSeek·OpenAI 호환 API
- Authenticode 인증서 구매·생성
- 요청하지 않은 UI 전면 개편, 의존성 추가, 폴더 개편

위 기능은 [v0.4.0 계획](V0.4.0-PLAN.md)을 따른다. Authenticode는 인증서가 없으므로 계속 `HOLD`다.

## 구현 순서

1. 취소 지연 재현과 프로세스 트리·단계별 시간 증거 확보
2. 취소 감독과 제한 시간 최소 수정, 실제 YouTube 취소·재개 검증
3. 설정 버튼과 다크 모드 입력 카드의 최소 CSS·UI 수정
4. updater 뒤 `DisplayVersion` 격리 재현과 최소 수정
5. 장시간 측정 도구 보완
6. 기본 테스트, 실제 화면, 설치·업데이트 회귀 검증

## 검증

기본 검증은 다음 네 명령을 모두 실행한다.

```powershell
npm.cmd test
npm.cmd run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo test --manifest-path src-tauri/fixture-worker/Cargo.toml
```

추가 검증:

- 밝은 화면·어두운 화면의 설정 버튼과 입력 카드 상태를 실제 Windows 앱에서 확인
- 실행 중 YouTube 내려받기와 Whisper 음성 인식을 각각 취소하고 최종 상태·잔존 프로세스·소요 시간 기록
- 취소 뒤 같은 작업을 마지막 정상 체크포인트부터 재개
- 공개 v0.3.3 설치본에서 v0.3.4 updater 설치·재실행·버전 표시·기존 작업 보존 확인
- 내려받기 병합 중 최대 임시 용량을 포함한 장시간 측정 재실행

## 완료 조건

1. 설정 진입점에 아이콘과 `설정` 문구가 있고 키보드로 접근할 수 있다. **PASS**
2. 다크 모드 입력 카드 제목·설명·아이콘이 배경과 구분되고 선택·비활성화 상태를 혼동하지 않는다. **PASS** (브라우저 대비 측정)
3. 실제 취소가 60초 이상 `취소 중…`에 머물지 않고 완료 뒤 관련 자식 프로세스가 0개다. **PASS** (YouTube 취소 ~1.4s/~3.4s)
4. 취소·앱 재실행 뒤 마지막 정상 체크포인트에서 재개한다. **PASS** (재개 후 yt-dlp 재기동)
5. updater 뒤 앱·실행 파일·제거 프로그램의 표시 버전이 모두 `0.3.4`다. **PASS** (인앱 v0.3.3→v0.3.4)
6. 장시간 측정에 내려받기 병합 순간의 최대 임시 용량이 포함된다. **PASS** (peak ~13.08 GiB)
7. v0.3.3의 후보·작업 데이터와 체크포인트를 보존한다. **PASS** (작업 15·파일 2,087·변경 0)
8. 기본 테스트와 실제 설치·업데이트 회귀가 PASS다. **PASS** (공개 5자산·minisign·인앱)
