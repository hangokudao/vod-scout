# VOD Scout v0.5.0

VOD Scout v0.5.0은 GPU 지원을 유지한 Windows용 정식 GitHub Release입니다.

## 주요 변경

- 사용할 수 있는 YouTube 한국어 자막이 있으면 그 자막만 사용하며 Whisper를 실행하지 않습니다.
- 자동 생성 한국어 자막 전체에 유효 구간이 없을 때 제작자 한국어 자막을 확인합니다.
- 사용할 자막이 없으면 영상 다운로드 전에 `Whisper 설정 후 진행` 또는 `취소`를 기다립니다.
- 로컬 파일은 사용자가 Whisper 설정을 확인하고 승인한 경우에만 분석합니다.
- Auto(GPU 우선)·GPU·CPU 모드, 품질 단계, CPU 사용량 설정과 GPU runtime을 유지합니다.
- 여러 영상의 순차 대기열, 후보 수 설정, 후보 품질 경고와 선택 후보 다시 음성 인식을 제공합니다.

## 알려진 한계

- GPU 실패 뒤 같은 구간을 CPU로 자동 처리하는 실제 실패 조건은 확인하지 못해 `DEFERRED`입니다.
- Cargo 결과는 `136 passed / 1 flaky / 1 ignored`입니다. flaky 1개는 테스트 준비 단계에서 `ping.exe` 자식 프로세스를 발견하지 못한 Windows 환경 의존 테스트이며, 실제 제품의 자식 프로세스 잔류 증거는 없습니다.
- 설치 파일은 Authenticode 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.
- updater 자산은 제공하지 않습니다. `.sig`, `latest.json`, updater zip은 배포하지 않으며 새 버전은 GitHub Release에서 직접 확인해야 합니다.
- 측정 근거가 없는 제한적 병렬 처리는 계속 비활성화되어 있습니다.
