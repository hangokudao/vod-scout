# VOD Scout v0.5.0-rc.1

이 버전은 GPU 지원을 유지한 Windows용 공개 시험판(Pre-release)입니다. 설치 파일은 코드 서명되지 않았으며 안정 버전 자동 업데이트 대상으로 배포하지 않습니다.

## 주요 변경

- `자동(GPU 우선)`, `GPU`, `CPU` 음성 인식 모드와 GPU runtime을 그대로 제공합니다.
- 한국어 자동 생성 자막을 우선 사용하고 자동 번역·다른 언어·`live_chat`은 제외합니다.
- 여러 영상의 순차 대기열, 후보 수 설정, 후보 품질 경고와 선택 후보 다시 음성 인식을 제공합니다.
- JKY 실제 영상 검증에서 `whisper.cpp-gpu` backend와 유효한 음성 인식 결과를 확인했습니다. ZJMp는 기존 후보 화면과 원본 미리보기 증거를 이번 시험판의 사용자 흐름 증거로 인정했습니다.

## 알려진 한계

- GPU 실행 실패 뒤 CPU로 자동 전환되는 실제 실패 조건은 확인하지 못했습니다. 이 항목은 `DEFERRED`이며 성공으로 표시하지 않습니다. 사용자는 필요할 때 CPU 모드를 직접 선택할 수 있습니다.
- 설치 파일과 앱은 Authenticode 코드 서명되지 않았습니다. Windows SmartScreen 경고가 표시될 수 있습니다.
- 이 시험판은 updater 자산을 제공하지 않습니다. `.sig`, `latest.json`, updater zip은 배포하지 않으며 다음 버전은 GitHub Release에서 직접 확인해야 합니다.
- 측정 근거가 없는 제한적 병렬 처리는 계속 비활성화되어 있습니다.
