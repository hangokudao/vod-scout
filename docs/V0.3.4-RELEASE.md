## 목표와 비범위

v0.3.4는 v0.3.3 공개 후 확인된 설정 진입점, 다크 모드 대비, 취소 지연, updater 뒤 Windows 제거 프로그램 버전 표시와 장시간 측정 누락을 수정하는 패치다.

YouTube 자막 우선 분석, 검색, 이야기 구간 탐색, GPU 음성 인식, 사용자 API, OCR, v0.4.0 P0~P7은 포함하지 않는다. Authenticode 인증서는 구매하거나 만들지 않았으며 계속 `HOLD`다.

## 사용자 변경 사항

- 화면 오른쪽 위 설정 진입점에 톱니바퀴 아이콘, `설정` 문구, 버전과 버튼 경계를 표시한다. 좁은 폭에서는 버전만 접고 설정 진입점은 남긴다.
- 밝은 화면·어두운 화면에서 입력 카드 배경·제목·설명이 테마 변수로 구분된다.
- 취소 중에는 종료 대상을 안내하고, 현재 작업의 worker·yt-dlp·FFmpeg·Whisper 자식 프로세스 트리만 제한 시간 안에 종료한다.
- 내려받기 병합 중 열린 파일 용량을 표본 수집하는 개발용 측정 도구를 문서화했다.

## 내부 변경 사항과 체크포인트 호환성

- 취소 신호는 디스크 저장보다 먼저 메모리에 반영하고, 잘못된 작업 ID로는 전역 취소 플래그를 켜지 않는다.
- Windows Job Object에 `TerminateJobObject` 기반 강제 종료와 유예·상한 시간을 둔다. 종료 범위는 현재 작업이 소유한 자식 트리로 제한한다.
- v0.3.3 작업 snapshot과 체크포인트 스키마는 유지한다. 기존 분석 결과를 다시 계산하지 않는다.
- 제품·릴리스 버전 정본을 `0.3.4`로 맞췄다. `release.yml` 릴리스 노트 경로, 설치 스모크 기대 버전, `generate-release-assets.mjs` 자산 이름·updater 노트 경로를 공개 v0.3.3과 같은 `VOD.Scout_<version>_x64-setup.exe` 계약으로 정렬했다. Authenticode는 추가하지 않았다.
