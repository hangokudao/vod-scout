# VOD Scout v0.3.4 릴리스 기록

상태: **HOLD — 계획만 완료, 구현·테스트·패키징 전**

계획 정본: [V0.3.4 안정성·접근성 후속 패치 계획](V0.3.4-PLAN.md)

## 목표와 비범위

v0.3.4는 v0.3.3 공개 후 확인된 설정 진입점, 다크 모드 대비, 취소 지연, updater 뒤 Windows 제거 프로그램 버전 표시와 장시간 측정 누락을 수정하는 패치다.

YouTube 자막 우선 분석, 검색, 이야기 구간 탐색, GPU 음성 인식, 사용자 API, OCR은 포함하지 않는다. Authenticode 인증서는 구매하거나 만들지 않으며 계속 `HOLD`다.

## 사용자 변경 사항

아직 구현하지 않았다. 계획된 변경은 다음과 같다.

- 설정임을 바로 알 수 있는 명시적인 버튼
- 밝은 화면·어두운 화면에서 읽을 수 있는 입력 카드
- 취소 대상과 진행 상태를 보여 주고 제한 시간 안에 끝나는 취소 흐름
- updater 뒤 Windows 앱 목록까지 일치하는 버전 표시

## 내부 변경 사항과 체크포인트 호환성

아직 구현하지 않았다.

- 취소 감독은 현재 작업의 worker와 자식 프로세스 트리로 제한한다.
- v0.3.3 작업 snapshot과 체크포인트 스키마는 유지한다.
- UI 스타일과 updater 메타데이터 변경으로 기존 분석 결과를 다시 계산하지 않는다.
- 호환성을 바꾸는 변경이 발견되면 구현 전에 이 절과 계획 문서를 먼저 갱신한다.

## 보안 수정

계획된 새 외부 전송이나 API 키 저장 경로는 없다. 프로세스 종료 범위는 현재 작업의 확인된 PID 트리 밖으로 넓히지 않는다. updater 수정은 `hangokudao/vod-scout`의 서명된 안정 버전 경로를 유지한다.

## PR 형식 자체 리뷰

### 변경 파일

구현 PR에서 실제 목록을 기록한다.

### 위험과 회귀 가능성

- 프로세스 트리 종료가 다른 작업이나 사용자 프로세스로 확장될 위험
- 취소 중 체크포인트가 마지막 정상 세대를 덮어쓸 위험
- 다크 모드 수정이 밝은 화면과 비활성화 상태를 흐리게 만들 위험
- updater 레지스트리 수정이 설치 경로나 기존 작업 데이터에 영향을 줄 위험

### 발견 사항과 조치

구현 리뷰에서 `PASS`, `HOLD`, `BLOCKED`로 기록한다. 미확인 항목은 PASS로 표시하지 않는다.

## 설치본과 SHA-256

아직 설치본을 만들지 않았다. exact merged commit에서 생성한 뒤 `BUILD-MANIFEST.md`와 함께 기록한다.

## 알려진 문제

- v0.3.3 설치본은 Authenticode 서명이 없어 SmartScreen 경고가 표시될 수 있다.
- 이 문서의 계획 항목은 아직 구현되지 않았다.

## 롤백 방법

v0.3.4 배포 뒤 문제가 발견되면 검증된 공개 v0.3.3 설치본으로 되돌린다. 롤백 전후에 기존 작업 폴더와 `current-job.json`을 삭제하지 않는다. 실제 v0.3.4 설치 파일명과 SHA-256은 빌드 뒤 이 절에 추가한다.
