## 구현 원칙

- 기본 분석은 계속 완전 로컬이며 OpenAI·Claude API 호출과 토큰 비용은 0이다.
- YouTube 입력도 다운로드가 끝난 로컬 원본을 재생한다.
- 플레이어가 직접 재생하지 못하는 코덱이면 FFmpeg가 저용량 검토용 MP4 프록시를 작업 폴더에 한 번 만들고 재사용한다.
- 채팅 분석은 전체 OCR이 아니라 먼저 화면 움직임만 저비용으로 측정한다.
- 삭제 대상은 `%LOCALAPPDATA%/com.vodscout.app/jobs/{job-id}`로 제한하고 경로를 검증한다.
- 진행 상태는 스냅샷과 체크포인트에 저장해 앱 재시작과 컨텍스트 압축 후에도 이어갈 수 있게 한다.

## 검증 게이트

1. TypeScript/Vitest와 Rust 단위 테스트 통과
2. 제품 E2E에서 후보 선택 → 플레이어 시점 이동, 복사·CSV, 삭제 흐름 통과
3. 실제 로컬 미디어에서 FFprobe → Whisper → 채팅 움직임 → 후보 생성 통과
4. 장시간 한국어 영상에서 전사 환각·후보 중복 자동 검증과 표본 점검
5. release 실행 파일과 NSIS 생성, 묶인 리소스와 로컬 미디어 재생 확인
6. `oracle-computer-use`로 Ubuntu 원격 연결과 최종 화면 전달 경로 확인
